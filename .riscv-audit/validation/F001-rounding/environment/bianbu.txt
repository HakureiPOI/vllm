API probe boundary

- FP16 implicit probe: compile exit 1
- FP16 explicit _rm probe: compile exit 1
- BF16 implicit probe: compile exit 1
- BF16 explicit _rm probe: compile exit 1

The FP16 diagnostics report unavailable vfloat16m1_t/vfloat16m2_t and

These results apply only to this tested GCC installation, flags and header.
